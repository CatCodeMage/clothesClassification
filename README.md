# Clothes classification
Fashion Product Images (Small) is a Kaggle dataset of about 44,000 colour product photos from an Indian fashion e-commerce site. Each image comes with a row in styles.csv holding catalogue attributes such as gender, category, article type, colour, season and usage. This project uses the images to predict a product's category, comparing classical models against convolutional neural networks.

Dataset: https://www.kaggle.com/datasets/paramaggarwal/fashion-product-images-small
